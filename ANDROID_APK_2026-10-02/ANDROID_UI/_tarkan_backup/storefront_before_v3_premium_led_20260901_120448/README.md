# EduVerse Storefront — Redesign V2

Bu klasör `eduverse.club` için bağımsız satış/tanıtım sitesidir.

## V2 değişiklikleri

- Windows PowerShell 5.1 için UTF-8/BOM karakter bozulması düzeltildi.
- Kabul edilmiş EduVerse launcher görseli marka varlığı olarak storefront içine kopyalandı.
- V1 genel SaaS görünümü kaldırıldı; EduVerse’e özgü aile/çocuk/keşif odaklı görsel sistem kuruldu.
- Android `web/` klasörüne dokunulmadı.
- Gerçek ödeme, deploy, DNS, commit ve push yapılmadı.
