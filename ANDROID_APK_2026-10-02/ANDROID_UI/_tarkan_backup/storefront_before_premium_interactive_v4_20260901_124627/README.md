# EduVerse Storefront — V3 Premium LED

Bu klasör `eduverse.club` için bağımsız satış/tanıtım vitrini olarak tasarlanmıştır.

## V3 tasarım ilkeleri
- Gerçek EduVerse Play Store ekran görüntüleri kullanılır.
- 6 renkli LED tema ışıkları: cyan, mavi, mor, pembe, altın, mint.
- Büyük boş karanlık alanlar kaldırılmıştır.
- Çocuk dostu enerji + ebeveyne güven veren premium görünüm dengelenmiştir.
- Mobil/tablet/desktop responsive yapı kullanılır.
- Android Capacitor kaynağı olan `../web/` değiştirilmez.

## Ticari güvenlik sınırı
- Gerçek web ödeme bu fazda başlatılmaz.
- Satın alma hakkı localStorage'a yazılmaz.
- DNS/deploy/commit/push yapılmaz.
- Play Store düğmesi yalnız resmi mağaza sayfasına gider.
