# EduVerse Storefront — Premium Interactive

`eduverse.club` için bağımsız müşteri vitrini.

## Ürün deneyimi
- Gerçek EduVerse uygulama ekranları kullanılır.
- Altı değişebilir tema ışığı bulunur.
- Işık Geçidi adlı kısa etkileşimli keşif deneyimi bulunur.
- Dokunuşlarda kullanıcı etkileşimi sonrasında hafif ses geri bildirimi vardır.
- Desktop, tablet ve mobil responsive tasarımdır.

## Güvenlik sınırı
- Android Capacitor kaynağı olan `../web/` değiştirilmez.
- Web satın alma entegrasyonu bu kurulumda açılmaz.
- DNS, deploy, Git commit veya Git push yapılmaz.
