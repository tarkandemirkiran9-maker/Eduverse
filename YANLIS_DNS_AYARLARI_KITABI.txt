Bu dosya, 10.09.2026 tarihinde EduVerse web sitesinde yaşanan

BUGÜN NE OLDU?
----------------------------------------------------------------------
EduVerse web sayfasında iki adet:

"WEBDE OYNA · 5 ÜCRETSİZ ODA"

girişi bulunuyordu.

Amaç:
Her iki girişin de Android PLAY5 sürümündeki çalışan sisteme benzer şekilde
oyunun ana girişine gitmesi ve kullanıcının 5 ücretsiz odayı seçebilmesiydi.

PLAY5 Android sürümü incelendi.

PLAY5 içinde çalışan 5 oda sistemi zaten mevcuttu.

Temel oda motoru örnekleri:

V48H_DOOR_ONLY
V48H_WITH_INNER
enterRoom
showRoomSoru
_showRoomHook
_doEnterRoom

Yani asıl problem oyun motorunun eksik olması değildi.

----------------------------------------------------------------------

https://play.eduverse.club/

Bazı yerlerde ise:

değildi.

Doğru mimari şuydu:

https://eduverse.club/
    -> mağaza / World Hub

https://eduverse.club/game/
    -> oyun / 5 oda sistemi

Fakat çalışma sırasında PLAY5 adı ile gerçek "play" subdomain kavramı
birbirine karıştı.

PLAY5:
Android çalışan referans paketinin / sürümünün adıydı.

play.eduverse.club:
Bir internet subdomain adresiydi.

Bunlar aynı şey DEĞİLDİR.

Bu ayrım kaybolunca web bağlantıları yanlışlıkla:

https://play.eduverse.club/

adresine bağlandı.

SONUÇ
----------------------------------------------------------------------
Telefon veya bilgisayar "WEBDE OYNA" butonuna basınca:

play.eduverse.club

adresine gitmeye çalıştı.

Ancak bu subdomain için çalışan DNS kaydı bulunmuyordu.

Sonuç:

- Sunucu bulunamadı
- Sunucuya ulaşılamadı
- DNS çözümleme başarısız
- Android telefonda oyun açılmadı
- iPhone tarafında da aynı adres açılamadı

Bu nedenle ilk bakışta problem DNS problemi gibi görünüyordu.

Fakat esas başlangıç sebebi:

YANLIŞ WEB ROUTE / YANLIŞ ABSOLUTE URL

idi.

YANLIŞ İKİNCİ MÜDAHALE
----------------------------------------------------------------------
Sorunun play.eduverse.club DNS kaydından kaynaklandığı görülünce,
ayrı bir Cloudflare Pages projesi kullanılarak oyunun:

eduverse

isimli Pages projesine deployment işlemi yapıldı.

Deployment adresi örneği:

https://eduverse-345.pages.dev/

Daha sonra:

play.eduverse.club

Cloudflare Pages custom domain olarak bu projeye bağlanmaya çalışıldı.

Cloudflare API sonucu:

DOMAIN=play.eduverse.club
STATUS=initializing

daha sonra:

STATUS=pending

oldu.

Fakat DNS kaydı yoktu.

DNS kontrolü:

DNS=FAIL

sonucu verdi.

Cloudflare OAuth yetkisiyle DNS kaydı oluşturulmaya çalışıldığında:

DNS_API_HTTP=403
DNS_WRITE_PERMISSION=MISSING_OR_FORBIDDEN

sonucu alındı.

Burada problem artık daha da büyüyebilirdi.

Çünkü gerçekte yeni play.eduverse.club subdomaini oluşturmaya ihtiyaç
yoktu.
