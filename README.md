# EduVerse daha temiz kopya

Bu klasor calisan `stemp` ve test edilen `stemp_temiz` klasorlerine dokunmadan hazirlandi.

Dosyalar:

- `index.html`: Sayfanin ana yapisi
- `style.css`: Ana gorunum kodlari
- `game.js`: Ana oyun JavaScript kodu
- Google Analytics ID: G-0TT3VWYV6M

Test icin `index.html` dosyasini ac.

Surge'a yuklemek icin CMD:

cd /d "%USERPROFILE%\Desktop\stemp_temiz_js"
surge . eduversetemp.surge.sh

## Anket ozelligi

Bu kopyada eedback.css ve eedback.js eklendi. Oyuncu 1-5 puan, secenek ve kisa not gonderebilir. Sonuc cihazda localStorage icinde saklanir ve Google Analytics varsa eedback_submit olayi olarak gonderilir.


## Basari karti

Bu kopyada share-card.css ve share-card.js eklendi. Sag alttaki Kart dugmesi basari karti olusturur, indirir veya telefonda paylasir.
